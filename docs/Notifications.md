# Private notifications

执行 `supabase/migrations/202609050002_private_notifications.sql` 后，私密空间导航栏会在当前账号右侧显示通知入口和未读数字。

- 新 Photos 或 Food 记录完成发布时，通知除发布者以外的所有有效账号。
- 记录收到评论时，只通知原发布者；自己评论自己不产生通知。
- 打开通知面板会显示最近 40 条通知，并将当前未读通知标记为已读。
- 页面可见时每 30 秒检查一次新通知，从后台切回页面时也会立即检查。
- 通知写入是附属操作；即使通知暂时写入失败，也不会回滚已成功的发布或评论。
