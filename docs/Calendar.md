# `/yfxl99/calendar` 日历手账

> 状态：月历框架与视觉样式已完成；手账内容、编辑能力和数据持久化尚未实现。

## 1. 页面定位

`/yfxl99/calendar` 是 `/yfxl99` 私密空间中的月度日历手账页面，用于按日期整理未来的图片、文字或其他生活记录。

页面位于 `(protected)` 路由组中，沿用现有私密 Session 校验和 `PrivateNavbar`。未登录用户不能直接访问。

## 2. 当前功能

- 一次展示一个完整月份。
- 星期顺序为周一到周日。
- 支持查看上个月、下个月和返回本月。
- 指定月份写入 URL 查询参数，例如：`/yfxl99/calendar?month=2026-09`。
- 查询参数格式为 `YYYY-MM`；无效参数自动回到当前月份。
- 当前日期按 `Asia/Shanghai` 时区计算，并使用不规则细线圆圈标记。
- 每个月根据第一天所在星期和当月天数自动生成所需周数。

## 3. 页面结构

```text
PrivateNavbar
└─ 月历页面
   ├─ 大号月份编号，例如 09
   ├─ 上个月 / 本月 / 下个月
   ├─ 英文月份与年份
   └─ 月度手账区域
      ├─ 桌面端左侧 Notes 留白栏
      └─ 周一至周日日期网格
```

Notes 区域和所有日期格目前只保留视觉框架，不展示示例手账、图片、贴纸或说明文字。

## 4. 视觉方向

最终 UI 参考横向月度拼贴手账，但不复制其中的照片和装饰内容。

- 使用冷灰色纸张作为页面底色，与 `/yfxl99` 原有深色文字和克制排版衔接。
- 通过多层低对比度 CSS 渐变生成轻微纸纤维纹理，不依赖外部背景图片。
- 顶部使用超大月份数字作为主要视觉识别，右侧显示英文月份与年份。
- 日期区域使用细黑线网格和浅灰留白格，月外空格使用稍深灰色区分。
- 左侧 Notes 区域使用深色底和低对比度书写辅助线，仅提供手账结构。
- 不使用上一版的黄色胶带、蓝色星期栏、卡片阴影或高饱和装饰。

## 5. 响应式行为

- 桌面端同时展示左侧 Notes 栏和完整月历。
- 小于 `1024px` 时隐藏 Notes 栏，将主要空间留给日期网格。
- 窄屏下月份标题与切换控件重新排列。
- 日期格保持足够的未来内容空间，不强行压缩；移动端通过横向滚动查看完整月份。
- 移动端显示“横向滑动查看完整月份”的操作提示。

## 6. 可访问性

- 月份切换区域使用带有可读名称的导航链接。
- 当前月份链接设置 `aria-current="date"`。
- 月历使用语义化 `table`、`caption`、列标题和 `time` 元素。
- 每个有效日期格提供完整中文日期标签，并注明当天状态。
- 月外空格对辅助技术隐藏。
- 保留项目全局键盘焦点样式，并在减少动态效果偏好下关闭控件过渡。
